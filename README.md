# Abajoo Motion Agent — Pilot 0.1

A deterministic GitHub Actions → Puppeteer → FFmpeg → MP4 **rendering smoke test**.

## Important limitation
The current explainer is **not yet Bang Motion AI generation**, not a high-quality 5-minute film and not an approved final animation. It is a typographic test fixture with seven sections, made only to prove rendering, automated validation, and artifact delivery.

## Usage
1. Open a pull request to run the **10-second smoke test** automatically.
2. Read the Render ERP Explainer job and download its erp-explainer artifact.
3. Once merged to the default branch, use Actions → Render ERP Explainer → Run workflow → choose 10, 30 or 300 seconds. **300 seconds is only a rendering benchmark**, not finished content.

## Roadmap
1. Confirm GitHub Action creates an MP4 artifact, H.264 1920×1080 @ 30fps, and passes FFprobe validation.
2. Integrate genuine [Bang Motion](https://github.com/bangtutorial/bang-motion) agent guidance, style brief, and continuous-world principles.
3. Build a coherent 5-minute storyboard with visual continuity, audio, voice-over, subtitles, and quality review.
4. Optionally add an AI coding agent, after API cost and security controls are agreed.

No paid AI API, publishing automation, or production deployment is configured in this pilot.
