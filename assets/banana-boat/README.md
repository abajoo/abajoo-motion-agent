# Four source screenshots required

Upload exactly four JPG screenshots to this directory, e.g. `01.jpg` through `04.jpg`, in chronological order. The original screenshots are user-provided chat attachments and have **not** been committed to GitHub automatically.

Once the images are committed, run **Actions → Banana Boat Motion (4 photo inputs) → Run workflow**.

The script crops 148 pixels from the top and applies camera drift, zoom-style crop and fades. It does not synthesize natural human or water motion. Input screenshots should be 689×1536 pixels (the format used in the pilot).

The original Bang Motion project is https://github.com/bangtutorial/bang-motion. This workflow is an FFmpeg photo-motion prototype; it does **not** yet use the Bang Motion skill as a creative coding agent.
